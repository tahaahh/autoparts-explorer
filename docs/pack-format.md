# صيغة حزمة البيانات المحلية — الإصدار 1

تقرأ الواجهة ملف JSON محلياً وتستبدل به قاعدة البيانات الحالية بعد موافقة المستخدم. الحد الحالي 25 ميغابايت. لا توجد مزامنة خفية أو تنزيل من API داخل التطبيق.

## البنية العامة

```json
{
  "manifest": {
    "packId": "maker.market.dataset",
    "version": "1.0.0",
    "schemaVersion": 1,
    "sources": [
      {
        "id": "source-id",
        "name": "اسم المصدر",
        "url": "https://example.org/source-record",
        "license": "اسم رخصة إعادة التوزيع كما وردت في المصدر",
        "attribution": "صيغة الإسناد المطلوبة"
      }
    ]
  },
  "db": {
    "meta": { "name": "اسم الحزمة", "version": 1 },
    "vehicles": [],
    "engines": [],
    "systems": [],
    "assemblies": [],
    "parts": [],
    "diagrams": [],
    "diagramItems": []
  }
}
```

كل صف له `id` نصي ثابت وفريد داخل جدول الحزمة. المركبة تربط بالشركة والطراز والجيل والسوق والسنوات الممكنة وبمعرّفات المحركات المتاحة. كل اسم متعدد اللغات كائن مفاتيحه `ar` و`en` و`fr`؛ لا تضع ترجمة مولدة على أنها نص المصدر. الحقول غير المتاحة تترك فارغة أو `null`، ولا تتحول إلى حقيقة سالبة.

## الربط بين الجداول

`vehicles[].engineIds` تشير إلى `engines[].id`. يحتوي كل نظام على `assemblyIds` تشير إلى تجميعات النظام. كل تجميعة تشير إلى `systemId` و`diagramId`، ويمكن أن تشير إلى `parentId` لإنشاء شجرة فرعية. يمنع الاستيراد مراجع التجميع المفقودة والحلقات الهرمية. كل `diagramItems[]` يربط `callout` وموضع/مساحة الرسم بمعرّف قطعة ومخطط.

يدعم المخطط عناصر نداء مستطيلة عبر `sx`, `sy`, `sw`, `sh`. تستخدم الواجهة SVG مضمناً لرسم مناطق الاختيار. بيانات صور الخلفية أو صور القطع تكون PNG/JPEG/WebP/GIF عبر مسار محلي آمن أو `data:image/...;base64`. لا تضع SVG غير موثوق داخل الحزمة. كل رسم وصورة يتطلب حقلي المصدر والرخصة.

## الأرقام والتوافق والصور

يمكن أن تحتوي القطعة على `name`, `function`, `location` بثلاثة مفاتيح لغوية، وعلى `partNumbers` و`crossReferences` و`images` و`fitments`. كل رقم OEM أو بديل يتضمن نوعه وحالة التحقق ومصدره. لا تعني تسمية الرقم `OEM` وحدها أنه تحقق.

حالة التوافق المسموح عرضها على أنها مثبتة هي `verificationStatus: "verified"`، ويلزمها مصدر ودليل `evidenceUrl`. لا يسمح المستورد بعرض حالة verified بلا هذه الحقول. التوافق الذي يأتي من بيانات طرف ثالث دون دليل واضح يبقى غير متحقق.

صورة القطعة عنصر كائن مثل `{ "src": "images/part-01.webp", "source": "رابط صفحة الملف", "license": "CC BY 4.0", "attribution": "المؤلف" }`. رابط المصدر والرخصة وسجل الإسناد جزء من بيانات الحزمة، وليس اختيارياً حتى لو كانت الصورة متاحة مجاناً للتنزيل.

## فحص الحزمة

يشغل معدّ الحزمة:

```bash
python3 tools/validate_pack.py path/to/pack.json
```

الأداة تتحقق من حجم الملف، وبنية JSON، ومعرّفات الجداول، والروابط بين السجلات، ومصادر الرخص المعلنة، وروابط الرسوم والصور والتوافق الموثق. لا تستطيع فحص صحة الوقائع أو منح رأي قانوني بشأن الرخصة. يجب أن يبقى ملف الرخصة الأصلي وإشعار الإسناد المرفق بكل مصدر ضمن الحزمة أو المستودع.

هناك فرق بين الحزمة والنسخة الاحتياطية المحلية: يضع التصدير `manifest.kind: "backup"`، ويضم بيانات هذا الجهاز ومفضلاته. لا يعد ذلك حزمة عامة صالحة لإعادة التوزيع.
