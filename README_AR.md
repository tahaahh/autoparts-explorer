# AutoParts Explorer — نموذج أولي مجاني

هذا مشروع PWA (تطبيق ويب قابل للتثبيت) يعمل على Android من المتصفح، ويمكنه التخزين المؤقت للعمل دون اتصال بعد فتحه عبر HTTPS مرة واحدة. ليس APK أصلياً بعد.

## مهم جداً
- البيانات الموجودة داخل `app.js` تجريبية ومحدودة لشرح الواجهة فقط.
- لا تحتوي هذه النسخة على قاعدة عالمية كاملة أو مخططات OEM حقيقية.
- لا تعتبر أرقام القطع أو التوافق مؤكدة؛ لا توجد أرقام OEM في البيانات التجريبية.
- لا تستخدم الرسومات التجريبية لتحديد قطع أو إجراء إصلاح فعلي.
- أضف فقط بيانات ورسومات يسمح ترخيصها بإعادة الاستخدام، واحتفظ بالمصدر والترخيص.
- ميزة توافق القطع مع السيارات غير مفعلة عمداً دون بيانات موثوقة.

## تشغيله من الهاتف فقط
أسهل طريقة مجانية لتجربته كتطبيق مثبت:
1. أنشئ حساب GitHub مجاني من المتصفح.
2. أنشئ مستودعاً عاماً جديداً باسم `autoparts-explorer`.
3. ارفع كل الملفات والمجلدات في هذا المشروع إلى المستودع.
4. من Settings > Pages، اختر النشر من الفرع `main` والمجلد `/ (root)`.
5. انتظر ظهور رابط الموقع. افتحه في Chrome على هاتف Android.
6. من قائمة Chrome اختر "Add to Home screen" أو "Install app".
7. افتح التطبيق مرة على الأقل مع الإنترنت حتى يتم تخزين ملفات الواجهة، ثم اختبر وضع الطيران.

قد تتغير أسماء الخيارات في GitHub. لا ترفع معلومات شخصية أو مفاتيح سرية إلى مستودع عام.

## الخصائص الموجودة
- بحث في السيارات المحلية.
- واجهة عربية وإنجليزية وفرنسية.
- قائمة أنظمة وتجميعات.
- مخطط SVG تجريبي بعناصر قابلة للنقر.
- تفاصيل قطعة ومفضلة محلية.
- تصدير/استيراد JSON.
- تخزين محلي لقاعدة البيانات.
- Service worker للتخزين المؤقت.

## بنية حزمة الاستيراد
يمكن أن تكون الحزمة كائن JSON يحتوي على:
- `vehicles`: مصفوفة المركبات
- `engines`: مصفوفة المحركات
- `systems`: مصفوفة الأنظمة
- `assemblies`: مصفوفة التجميعات
- `parts`: مصفوفة القطع
- `diagrams`: مصفوفة المخططات
- `diagramItems`: مصفوفة العناصر التفاعلية

مثال عنصر مخطط:
```json
{
  "id": "item-1",
  "diagramId": "diagram-1",
  "partId": "part-1",
  "callout": 1,
  "x": 400,
  "y": 100,
  "shape": "rect",
  "sx": 350,
  "sy": 80,
  "sw": 100,
  "sh": 40
}
```
ملاحظة: هذا النموذج الأولي يرسم عناصر تجريبية بمناطق مستطيلة. يمكن تطوير عارض SVG لقراءة ملفات SVG الأصلية ذات العناصر المعرّفة، مع ضرورة التأكد من سلامة الملفات المستوردة.

## مصادر للبحث عن البيانات
- NHTSA vPIC: https://vpic.nhtsa.dot.gov/api/
- VehiclesDB: https://github.com/vehiclesdb/vehiclesdb
- Android Studio: https://developer.android.com/studio

هذه المصادر لا تعني أن كل مخططات السيارات العالمية متاحة مجاناً. افحص ترخيص كل مصدر وتغطية بياناته قبل الاستيراد.
